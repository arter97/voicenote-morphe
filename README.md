# Voice Recorder Patches

Patches for **Samsung Voice Recorder** (`com.sec.android.app.voicenote`), applied with the
[Morphe](https://morphe.software) patcher.

Samsung Voice Recorder only lists, plays and transcribes recordings it made itself, plus
a few `.m4a`/`.amr`/`.3ga` files from elsewhere. These patches make it a player and
transcriber for audio recorded by other apps, such as call recorders.

## Import any audio files

### Importing

- **Any format in `Recordings/`:** every audio file that Android's media library
  indexes under the top-level `Recordings/` folder of any storage volume (MP3, FLAC,
  WAV, Ogg, AAC, ...), not just `.m4a`/`.amr`/`.3ga`.
- **`.oga` anywhere:** for call recorders such as BCR.
- **Additional folders:** chosen in the app's **Settings → Additional folders**.
  - **Add folder** opens the system folder chooser.
  - Each folder is listed with its name, its full path, and a button to remove it.
  - Each folder also gets its own entry in the recordings list menu (the left pane),
    next to *Voice recordings* and *Call recordings*.
- **All recordings** shows imported files alongside the app's own recordings, instead of
  hiding them under *Other recordings*.
- **`.m4a` files without Samsung's metadata** in those folders are treated as recorded by
  the app, which unlocks the features it limits to its own recordings.

### Transcription and AI features

- Transcribe and the Galaxy AI features (summary, translation, ...) are available for
  every imported format except `.amr`/`.3ga`. The app's own decoder handles MP3, FLAC,
  WAV, AAC and Ogg Vorbis.
- Files it cannot open, such as Ogg Opus, fall back to Android's decoders.
- Transcripts and AI results are stored in the app's database. Audio files from other
  apps are not modified.

### Waveform

- Real waveforms for formats the app cannot parse, generated by decoding with Android's
  decoders and scaled like the app's own.
  - Long recordings are split into segments decoded in parallel on all CPU cores.
  - Results are cached per file in the app's cache folder.
  - The player opens right away with a flat, scrollable waveform, so you can seek while
    the real one is generated.
- Samsung's placeholder pattern for files from other apps is replaced by the real waveform.

### Permissions

- Reading other apps' audio needs only the media access the app already has.
- Transcribing, renaming or deleting files the app did not create needs
  **All files access**. Adding the first additional folder opens the system page for it.

## ⚠️ Notes and limitations

- **Signature check:** the patch only targets the Samsung-signed APK of the supported
  versions.
- **Mount-based installs:** installs that mount the patched APK over the original keep the
  original manifest. The patches therefore add no manifest entries; everything runs from
  the app's existing components.
- **Media library:** folders containing a `.nomedia` file are not indexed by Android's
  media library, so their files cannot be imported.
- **Folder chooser:** the system chooser does not allow the storage root, `Download` or
  `Android/data`.
- **Re-checking files:** files imported before patching keep the type they were imported
  with. To re-import one, move it out of its folder and back.
- **Trash:** the app's trash screen only lists `.m4a`/`.amr`/`.3ga` files. Other deleted
  files go to the system trash and can be restored from My Files.
- **21.5.85.69:** this version has no decoder fallback, so Ogg Opus files play but cannot
  be transcribed there.
- **Labels:** labels added by the patches are English only.

## 🛠️ Building

Requirements:
- JDK 17 or newer
- Android SDK
- GitHub Packages credentials for the Morphe dependencies: `gpr.user` and `gpr.key` in
  `~/.gradle/gradle.properties`, or `GITHUB_ACTOR` and `GITHUB_TOKEN`

```sh
ANDROID_HOME=/path/to/Android/Sdk ./gradlew buildAndroid
```

The patches bundle is written to `patches/build/libs/voicenote-morphe-r<N>-<rev>.mpp`. The extension
is built into it as `extensions/voicenote.mpe`.

To patch an APK with the Morphe desktop CLI:

```sh
java -jar morphe-desktop-<version>-all.jar patch -p patches/build/libs/voicenote-morphe-r<N>-<rev>.mpp base.apk
```

### Layout

| Path | Contents |
|------|----------|
| `patches/src/main/kotlin/app/morphe/patches/voicenote/` | Patches and fingerprints |
| `extensions/voicenote/` | Extension code that runs inside the app |
| `extensions/voicenote/stub/` | Compile-only stubs of the app classes the extension calls |
